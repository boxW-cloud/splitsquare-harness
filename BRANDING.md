# Branding and trademark boundary

This project is published under the independent name **SplitSquare Harness**. Its application identity, package name, executable, installer, window chrome, and release artifacts use that name rather than an upstream vendor identity.

The SplitSquare mark in `assets/icon.svg`, `assets/icon.png`, and `assets/icon.ico` is original project artwork: a square divided diagonally into a black upper-left triangle and a white lower-right triangle. It is not derived from the DeepSeek logo or Harness favicon. Contributors should not replace it with third-party brand artwork unless the project has documented permission for that exact public use.

The application consumes the open-source `@deepseek-ai/dsh` dependency under its own MIT License. That software license does not grant rights to use DeepSeek names, logos, trade dress, or other brand elements as this project's identity. DeepSeek is named in this repository only where necessary to identify compatibility, dependencies, upstream provenance, licenses, or external links.

Public project descriptions should include this disclaimer:

> SplitSquare Harness is an independently maintained third-party open-source project. It is not affiliated with, authorized, endorsed, or sponsored by DeepSeek. “DeepSeek” is used only to identify interoperability and upstream provenance. This project claims no rights in DeepSeek names, marks, or other brand elements.

The release check rejects the previous application identity and known prototype icon. It cannot police GitHub repository names, descriptions, topics, social previews, manual Releases, domains, stores, screenshots, or old history; those require human review before publication. The SplitSquare name is a working independent identity, not a legal trademark-clearance opinion.
