# Code of conduct

We want project spaces to be safe, useful, and welcoming. Participants must:

- discuss ideas and code without personal attacks or harassment;
- respect privacy, identities, accessibility needs, and differing experience levels;
- give actionable technical feedback and assume good faith while evidence is gathered;
- avoid publishing another person's credentials, private logs, session content, or security reports;
- follow maintainer directions during moderation and coordinated vulnerability disclosure.

Unacceptable conduct may result in edited or removed content, temporary restrictions, or a permanent ban. Report conduct concerns privately through the repository's moderation or security channel. Maintainers will limit report details to the people needed for a fair response and will not retaliate against good-faith reports.
