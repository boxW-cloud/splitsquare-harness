# Brand assets

`icon.svg` is the original SplitSquare Harness mark: a square divided diagonally into a black upper-left triangle and a white lower-right triangle. `icon.png` is the transparent 1024 px raster asset used by Electron, and `icon.ico` contains 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 px frames for the Windows executable, taskbar, shortcuts, and Squirrel installer.

The SplitSquare artwork is not derived from the DeepSeek logo or the upstream Harness favicon. DeepSeek is identified elsewhere only for compatibility and upstream attribution; SplitSquare Harness is independently maintained and is not an official DeepSeek product. See [`BRANDING.md`](../BRANDING.md).

The toolbar SVG files are the unmodified `panel_left_24_regular`, `arrow_left_24_regular`, and `arrow_right_24_regular` assets from Microsoft's `@fluentui/svg-icons` 1.1.337 package (MIT). They match the Windows-style reference chrome without drawing replacement icons in CSS.
